# Organizze Clone

Este projeto é uma réplica do famoso aplicativo Organize, desenvolvido em Java para Android. O objetivo deste projeto foi aprender e implementar diversas funcionalidades relacionadas ao desenvolvimento de aplicativos móveis, incluindo integração com Firebase, uso de Realtime Database, navegação entre Activities, e muito mais.

## Funcionalidades

- Cadastro e autenticação de usuários com Firebase Authentication.
- Adição, edição e remoção de movimentações financeiras.
- Cálculo de saldo mensal e total.
- Navegação intuitiva entre diferentes telas.
- Interface de usuário responsiva e moderna.

## Tecnologias Utilizadas

- Java
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- ConstraintLayout
- DataBinding e ViewBinding
